# Notafo (Notes + Tasks + Focus)

Notafo is a premium, local-first personal productivity suite for Android. It combines a highly secure note-taking experience with an advanced task management system and customizable deep-work tools, all within a fluid Material 3 design.

## 🚀 Version 2.4.1 Highlights - "The Identity Update"

This major update brings Notafo its own unique identity through advanced UI polish, hardened security, and unified productivity features.

### ✨ Fluid UI & Identity (v2.4.1)
- **Swipe-to-Action**: Effortlessly organize your lists. Swipe right to **Trash** or left to **Archive**.
- **Tactile Feedback**: Subtle "Scale on Tap" micro-interactions give every card a physical, responsive feel.
- **Modern Navigation**: Seamless slide-and-fade transitions between all main screens.
- **Modal Bottom Sheets**: Thumb-friendly, modern menus replacing outdated dropdowns.
- **Material 3 Search**: A fully integrated, animated SearchBar experience.

### ⏱️ Advanced Productivity (v2.4)
- **Unified Search**: Search across both Notes and Tasks instantly in one place.
- **Customizable Focus Timer**: Personalize your deep-work sessions with adjustable Focus and Break intervals.
- **Subtask Management**: Track granular progress with subtask checklists and completion indicators in the main list.
- **Dedicated Trash Bin**: A secure place to manage, restore, or permanently delete your notes.

### 🛡️ Security & Core Enhancements
- **Hardened Secret Vault**: Mandatory biometric/device security (PIN/Fingerprint). No setup, no access.
- **Full Markdown Support**: Headers, blockquotes, links, and improved lists in a real-time editor.
- **Refined Task Logic**: Automatic filtering of completed items to keep your active list focused.
- **Beautifully Bright Icons**: Consistent brilliant white icons in the editor for a professional look.

## 🛠️ Technical Stack

- **Language:** Kotlin 2.3.21 (K2 Compiler)
- **UI Framework:** Jetpack Compose (1.7+) with Material 3
- **Database:** Room with FTS4 support
- **Dependency Injection:** Hilt
- **Build System:** Gradle 9.2.1 (AGP) with KSP 2.3.8
- **Localization:** Multi-language support (English/Español/Français/etc.)

## 📦 Installation

Notafo is designed for Android 13.0 (API 33) and above. Build the project from source using Android Studio Ladybug or later.
