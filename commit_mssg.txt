v2.1.1: Stability and Maintenance

This minor update addresses a critical startup crash and performs a comprehensive codebase cleanup to ensure technical excellence.

Key Fixes:

1. 🚀 Stability Improvements:
   - Resolved a fatal crash on startup by transitioning MainActivity to FragmentActivity.
   - Fixed theme compatibility issues between AppCompat and Material 3.

2. 🧹 Codebase Optimization:
   - Conducted a project-wide sweep to remove unused imports and dead code.
   - Eliminated redundant SDK version checks (Project now targets minSdk 33).
   - Removed unused ViewModel properties and functions in Task and Vault ViewModels.

3. 🛠️ Technical Refinements:
   - Optimized state delegation in EditorScreen to resolve state-reading warnings.
   - Refined import structures in Home, Task, and Vault screens.
